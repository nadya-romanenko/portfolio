## ШАГ 1 — АНАЛИЗ ВАКАНСИИ

Разбери вакансию:
- Позиция и компания
- Топ-5 ключевых задач (что предстоит делать)
- Ожидания первых 1/2/3 месяцев (если указаны — это золото)
- Hard skills и инструменты
- Soft skills

Сравни с PROFILE. Выведи таблицу:

| Требование | Статус | Мой кейс или комментарий |
|---|---|---|
| … | ✅ Есть / ⚠️ Частично / ❌ Нет | … |

Отдельными блоками:

**Вынести вперёд** — какие кейсы из профиля бьют точно в задачи вакансии
**Не педалировать** — пробелы, которые лучше не акцентировать

→ СТОП. Жди подтверждения.

## ШАГ 2 — 10 ИДЕЙ ЧТО СДЕЛАТЬ ДЛЯ КОМПАНИИ

Это не просто «список идей» — это конкретные исследования и материалы,
которые нанимающая команда получит ДО первой встречи и скажет
«она уже работает».

**Источники для идей:**
- Что написано в задачах вакансии — делай именно по их боли
- Ожидания первых месяцев (если есть) — покажи что ты уже это сделала
- Что компания явно не делает хорошо (видно с сайта/соцсетей/отзывов)

**Форматы (не ограничивайся этим списком):**
исследование рынка, аудит воронки, конкурентный анализ, SERM,
готовая стратегия, пересобранный лендинг (прототип), контент-план,
гипотезы с приоритизацией, дашборд метрик, план первых 90 дней,
разбор ЦА с инсайтами, AI-аудит процессов, финансовая модель юнит-экономики

По каждой идее:
- **Название** (конкретное, не абстрактное)
- **Формат**
- **Почему им это важно** (одно предложение, без воды)
- **Сложность** (1-3 дня / 1 неделя)

→ СТОП. Жди выбора — какие идеи берём в работу.

## ШАГ 3 — ИССЛЕДОВАНИЕ КОМПАНИИ

Используй web_search. Все цифры — только из реальных источников.
Не выдумывать данные, не додумывать. Если не найдено — честно писать.

### 3.1 TAM / SAM / SOM
- TAM: весь рынок (ниша + регион), источник, CAGR
- SAM: целевой сегмент компании с обоснованием сужения
- SOM: доля компании сейчас + реалистичный потенциал (3 года)
- Ссылки на источники обязательны

### 3.2 Конкуренты (топ 7-10)
По каждому:
- УТП и позиционирование
- Цены / модель монетизации
- ЦА и ключевые каналы привлечения
- 2-3 сильные стороны
- 2-3 слабые стороны

### 3.3 SERM компании (COMPANY_NAME)
Ищи отзывы: otzovik, irecommend, dreamjob, hh.ru/companies,
vc.ru, Habr, Telegram, 2gis, Google Maps
- Что хвалят (топ-3, из реальных отзывов)
- На что жалуются (топ-3, из реальных отзывов)
- Незакрытые боли клиентов / пользователей
- Репутация как работодателя (если есть данные)

### 3.4 SERM конкурентов (топ-3)
По каждому:
- Рейтинг и тональность
- Главный плюс
- Главная боль
- Незакрытая боль аудитории

### 3.5 SWOT компании
- **Strengths**: реальные конкурентные преимущества
- **Weaknesses**: слабые места vs конкуренты
- **Opportunities**: незакрытые ниши, тренды, точки роста
- **Threats**: риски, сильные конкуренты, внешние угрозы

### 3.6 Аудит маркетинговой воронки
Пройди путь как потенциальный клиент:
- Лендинг: оффер (конкретный или категорийный?), структура, CTA,
  соцдоказательства, есть ли цены
- Трафик: каналы (SimilarWeb / открытые данные), SEO, соцсети,
  платная реклама
- Прогрев: лид-магниты, email/TG, путь от первого касания до оплаты

Итоговая таблица:

| Этап | Оценка (1-10) | Главная проблема | Что тестировать |
|---|---|---|---|

Топ-3 узких места воронки с влиянием на выручку.

### 3.7 Гипотезы роста
10 конкретных гипотез для компании:

| # | Гипотеза | Область | Ожидаемый эффект | Сложность (1-5) | Категория |
|---|---|---|---|---|---|

Приоритизация по Impact/Effort:
- 🔥 Быстрые победы (высокий эффект, низкая сложность) — делать первыми
- 🚀 Стратегические ставки (высокий эффект, высокая сложность)
- 💡 Эксперименты (низкий эффект, низкая сложность)
- ⛔ Не сейчас (низкий эффект, высокая сложность)

→ СТОП. Покажи все результаты. Жди подтверждения перед записью в таблицу.

## ШАГ 4 — GOOGLE ТАБЛИЦА

Спроси пользователя: «Скинь ссылку на Google Sheets или дай разрешение
создать новую таблицу — создам через gspread.»

Название новой таблицы:
**`[COMPANY_NAME] — Исследование [ДД.ММ.ГГГГ]`**

Создай через gspread (OAuth token: `~/.config/gws/gspread_token.json`,
credentials: `~/.config/gws/credentials.json`):

```python
import gspread
from google.oauth2.credentials import Credentials
from google.auth.transport.requests import Request
import json, os

TOKEN_FILE = os.path.expanduser("~/.config/gws/gspread_token.json")
CREDS_FILE = os.path.expanduser("~/.config/gws/credentials.json")
SCOPES = [
    "https://www.googleapis.com/auth/spreadsheets",
    "https://www.googleapis.com/auth/drive",
]

with open(TOKEN_FILE, "r", encoding="utf-8") as f:
    creds = Credentials.from_authorized_user_info(json.load(f), SCOPES)
if creds.expired and creds.refresh_token:
    creds.refresh(Request())

gc = gspread.authorize(creds)
sh = gc.create(f"{COMPANY_NAME} — Исследование {date}")
```

Листы таблицы:
1. `📋 Обзор` — сводка всех блоков с оценками и приоритетами
2. `📊 Рынок TAM-SAM-SOM` — данные с источниками
3. `🥊 Конкуренты` — сравнительная таблица
4. `💬 SERM` — компания + конкуренты
5. `🎯 SWOT` — матрица 2×2
6. `🔍 Воронка` — аудит по этапам
7. `🚀 Гипотезы` — таблица с приоритизацией

После записи — расшарь таблицу на email пользователя и выведи ссылку.
